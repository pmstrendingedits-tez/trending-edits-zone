# Trending Edits Zone

A Next.js + TypeScript + Tailwind CSS starter inspired by the public visual concept of the referenced website, redesigned for Trending Edits Zone.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Included
- Responsive dark creative homepage
- Header, hero, categories, resource cards, about and footer
- Demo admin portal at `/admin`
- TypeScript, Tailwind CSS, Next.js App Router

## Important
The admin screen is only a UI demo. Before production, connect secure authentication, Neon Postgres, validation, image storage, and server-side CRUD actions. Do not use client-only demo login for a real admin account.
