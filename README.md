# Trending Edits Zone

A modern, responsive blog-style landing page built with:

- Next.js App Router
- TypeScript
- Tailwind CSS
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Build for production

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Upload this project to GitHub.
2. Open https://vercel.com/new
3. Import the GitHub repository.
4. Keep the default Next.js settings.
5. Click Deploy.

## Important

The sample images use Unsplash remote URLs. Replace them with your own images or a storage provider when developing the complete blog and admin portal.
